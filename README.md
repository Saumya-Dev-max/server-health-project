# Linux Server Health Check Automation
This project contains a Bash script to perform basic Linux server health checks.
## Checks Included
- Hostname
- Current user
- Date and time
- System uptime
- Root disk usage
- Memory usage
- Top memory-consuming processes
- SSH service status
- Nginx service status
- Listening ports
## How to Run
```bash
chmod +x scripts/server-health.sh
./scripts/server-health.sh
